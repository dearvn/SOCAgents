# Event risk checklist

Check the Event and News report before proposing ideas.

If a high-importance release is due before the idea would trigger:
- Name the release and its time in the rationale.
- Prefer a trigger that waits for the first 5-minute close after the release.
- Long options bought before a release can lose value quickly after it, as implied volatility falls. Mention this for any long-premium idea.
- If the idea only works when the release goes one way, answer "no trade before the release" instead.

After the release:
- Levels from before the release can break quickly. Check them against the latest data in the reports.

For the Risk Officer:
- Flag any idea whose entry window overlaps a high-importance release.
